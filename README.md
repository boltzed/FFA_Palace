# The Palace (FFA_Palace)

The Palace - Chivalry 2's first space themed map. This map takes place in a floating palace in space with a galaxy skybox available to view. The map has four custom Greek god themed weapons with unique abilities and skins applied to them as well as a healing well that heals and restores stamina for users making this a perfect dueling map for all.

## Install

Install through the Unchained launcher, or download `FFA_Palace.pak` from the latest release.

## Source

`Content/Mods` holds the Unreal source assets for the map (ArgonSDK / UE 4.25).
Copy the `Mods` folder into your ArgonSDK project's `Content` folder and open
`Mods/OvergrownTemple/FFA_Palace`.
